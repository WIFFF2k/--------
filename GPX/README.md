# 补充路线

六条铁路 GPX 使用 gpx.studio 铁路模式采用的 BRouter rail 服务生成，站点来自 OpenStreetMap / Photon。路线是铁路网络规划结果，并非指定日期的实测轨迹或某一车次的精确径路；日期由用户指定

汉口与南京南、南京站分别选取不同站点。犀浦使用国铁轨道端点，避开邻近地铁吸附；所有下载路线的 BRouter 路段标签均为 railway=rail。往返路线分别请求服务，不简单复制或倒序生成

routes.json 记录各文件、指定日期、点数、规划距离、服务请求地址和 SHA-256。青甘大环线.gpx 保留用户原文件不改写，展示与 CSV 导出日期覆盖为 2020-07-21

## 下载、转换与导入

完整操作见[项目 README：下载铁路 GPX → 转 CSV → 导入灵敢足迹](../README.md#下载铁路-gpx--转-csv--导入灵敢足迹)。

使用 gpx.studio 铁路模式下载站间路线，按日期转换为十四列 CSV，再导入灵敢足迹。新增点 `locationType=0`，两组坐标填齐、数值字段补齐、时间戳唯一；此前错误导入的同时间戳记录需先处理，重复导入不会可靠地更新旧字段。直接按流程导入完整路线，无需每次重新做三点测试。
